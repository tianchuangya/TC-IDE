# Windows 实机验收清单

本清单用于完成交接文档第 5 节 P0 中尚未完成的"Windows 11 实机逐项测试"。
自动化能覆盖的部分已经进了 CI（单元测试、Clippy、类型检查、`--self-check` 状态层自检、
Linux 端无窗口渲染一帧），**下面每一项都需要在真机上人工确认**。

建议先在 Windows 11 机器上构建：

```powershell
cargo build --release
cargo run --release -- --self-check   # 状态层自检，应当全部通过
cargo run --release
```

## 1. 窗口与 DPI

- [ ] 在 100% / 150% / 200% 缩放下启动，界面不模糊、不重叠、不留黑边。
- [ ] 把窗口拖到另一台不同 DPI 的显示器，文字、图标、点击区域同步缩放（`WM_DPICHANGED`）。
- [ ] 最大化、还原、拖拽调整大小；关系图、编辑器、终端网格随之变化，终端换行正确。
- [ ] 窗口缩到很小时不发散、不崩溃（网格会回落到最小列/行）。

## 2. 编辑与输入

- [ ] 中文 IME 组合输入、候选窗定位、提交后光标位置正确。
- [ ] 鼠标拖选、Shift 扩选、跨行方向键、Home/End、删除/退格边界正确（含 CJK 字符）。
- [ ] `Ctrl+A/C/X/V/S/Z/Y` 与字号快捷键行为正确；系统剪贴板双向一致。
- [ ] 光标与选区是否精确落在字形上（字形宽度已改为 DirectWrite 实测）。
- [ ] 打开大文件（> 1 万行）观察滚动与输入延迟，记录卡顿点（已知缺口：无虚拟化）。

## 3. 标签、脏状态与会话

- [ ] 打开多个文件出现标签；脏文件显示 `•`；点击标签切换内容与光标位置。
- [ ] 关闭脏标签弹出原生确认框；选择"否"丢弃、选择"是/取消"行为符合预期。
- [ ] `Ctrl+W` 关闭当前标签；关闭全部后界面回到空白状态。
- [ ] 退出后重新启动：项目、打开的文件、最近项目自动恢复。

## 4. 项目与关系图

- [ ] 新建项目（含 Rust/Python/C/C++/Java/Go/Web）生成的模板文件可编译/运行。
- [ ] 关系图：悬停符号自动聚焦；范围 chip 在 项目/文件夹/文件/符号/自动 间切换有效。
- [ ] 搜索框按符号名与路径过滤；`Tab`/方向键切换范围与关系类型。
- [ ] 标记点击折叠/展开类与文件夹节点；点击卡片跳转到正确文件与行。
- [ ] 键盘上/下移动选择、回车跳转、空格折叠。

## 5. 终端

- [ ] Build、Run、Output 与新增终端都能输入输出；`Ctrl+Tab` 切换。
- [ ] 面板正文滚轮翻看历史、输入后自动回到底部；标题显示偏移行数。
- [ ] 面板正文拖选 + `Ctrl+Shift+C` 复制；`Ctrl+C` 仍然中断当前命令。
- [ ] Detach 弹出窗口：独立滚动、拖选复制、中文输入、关闭后 IDE 仍持有同一会话。
- [ ] 关闭弹出窗口与 IDE，任务管理器中无残留 `powershell.exe`。
- [ ] 终端网格与窗口尺寸一致：执行 `mode` 或输出长行，确认换行位置正确。

## 6. AI 与扩展

- [ ] AI 页面填写 Endpoint/模型/Key（Key 仅驻内存），点"测试连接"得到明确结果。
- [ ] 输入提问并回车：AI 终端流出回答；`Ctrl+C` 可取消；超时提示可读。
- [ ] 故意填写错误 Key 或错误模型，确认错误信息是 401/404 的可读说明。
- [ ] Debuggers/Formatters 的 CHECK 反映真实 PATH 状态（装与不装各测一次）。
- [ ] 有 `clang-format`/`ruff` 等工具时，"格式化当前文件"生效且编辑器内容刷新。
- [ ] 在项目里放一份 `.tc-ide-catalog.conf`，安装扩展后校验通过与不通过各测一次。

## 7. 打包

- [ ] 勾选可执行文件/ZIP/MSIX 打包，进度随真实构建阶段推进而不是匀速转圈。
- [ ] 产物存在时 `BUILD-RESULT.txt` 显示路径、大小、耗时；失败时显示失败命令。
- [ ] 选择证书后 MSIX 由 `signtool` 签名；受密码保护的证书给出可理解的失败信息。
- [ ] 未选择证书时不生成签名，也不提示"已完成签名"。

## 8. 记录结果

- [ ] 把发现的问题写回 `docs/KNOWN-ISSUES.md`，并在 `docs/HANDOFF.md` 第 5 节勾选对应条目。
- [ ] 若改动代码，按交接文档第 7 节执行 `cargo fmt --check`、`cargo test --all-targets`、
      Windows 目标 `cargo check` / Clippy，再推送并等待 CI 全绿。
