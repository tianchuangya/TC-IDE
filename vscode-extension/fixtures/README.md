# Fixtures

Sample projects for the extension's checks and for the F5 development host.

- `rust/` — a struct with methods, a free function that calls them, a method
  that calls two others, and a recursive function. That gives the call
  hierarchy something to show in both directions, and gives the editor a
  definition and several references to decorate.

The brief asks for C, C++, Rust, Python and Java fixtures. Only Rust exists so
far; the others are not written yet and this file says so rather than implying
the set is complete.
