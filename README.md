# TC-IDE

TC-IDE 是一个 Rust 原生、低色彩噪声、强调空间关系与丝滑动效的 IDE 实验项目。它沿用 Zed 的核心产品方向：原生窗口、每帧统一绘制、后台语义分析，以及不依赖 HTML/CSS 的界面。

当前第一个可运行原型包含：

- 原生 X11 窗口与 60 FPS 动画循环；
- 根据显示器分辨率自动设置窗口尺寸与界面缩放，高分屏使用更大的原生字体；
- 双缓冲场景绘制，减少持续动画时的闪烁；
- 项目关系图的完整层级：`项目 → 文件 → Class → 函数`；
- 鼠标经过节点时自动聚焦上下游关系，无需手动切换“函数/Class/路径”；
- 文件树可点击切换，编辑器支持输入、退格、换行与方向键；
- 可从项目树新建文件，并根据扩展名自动选择语言包；
- 新文件会自动识别后缀；缺失的对应语言包会进入安装流程；
- 编辑器根据当前语言提供关键字补全候选，按 `Tab` 接受首项；
- `//`、`#`、`--` 注释会被渲染成带指向尖角的单色标签气泡；
- `Extensions → Programming Languages` 提供可滚动语言包目录，安装状态持久化到用户配置；
- 内置 Rust、Python、TypeScript/JavaScript、C/C++、Go、Java、C#、Kotlin、Swift、Zig 等 29 个语言/格式入口，未知格式回退为 Plain Text；
- 关系图支持滚轮缩放，Package 菜单支持目标选择与构建动画；
- 编辑区、项目树与语义图使用同一帧绘制；
- 零网页运行时、零 CSS、零第三方 Rust 依赖。

## 运行

Ubuntu/Debian 需要 X11 运行库：

```bash
cargo run --release
```

按 `Esc` 或关闭窗口退出。

## 路线

此原型先验证 TC-IDE 的视觉语言与关系图交互。后续阶段会将窗口层替换/扩展为 Zed 的 GPUI 路线，加入 Tree-sitter、LSP、GPU 字形动画、项目索引器和多平台打包器。详见 [架构说明](docs/ARCHITECTURE.md)。
